Object Detection & Tracking

YOLO11 finds objects in every frame and a SORT tracker (Kalman filter + Hungarian matching) gives each one a stable ID. Everything runs in your browser — the video never leaves your device.

How it works

  1. Video input: frames from your webcam, a video file or the demo scene are drawn to a canvas.
  2. Detection: each frame is letterboxed to 416×416 and passed to YOLO11n (pre-trained on COCO, 80 classes) via ONNX Runtime Web. Boxes below the confidence threshold are dropped and overlapping boxes are merged with non-maximum suppression.
  3. Tracking: SORT predicts where every known object moved with a Kalman filter, matches new boxes to those predictions with the Hungarian algorithm on IoU, and keeps the same ID while the object is visible.
  4. Display: boxes, labels, track IDs, motion trails and live FPS / object counts.
